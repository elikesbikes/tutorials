# endurance host routers

Host-specific Traefik routers for endurance (Hermes agent host, VM 116, 192.168.5.46).
The routers that used to live here belonged to the retired physical endurance (cooper, ha, nas,
syncthing, urbackup, mcc-dashboard, security) and were removed 2026-10-02; they are in git history.
Add one file per router here (hot-reloaded). Container-based routes use Docker labels instead.
